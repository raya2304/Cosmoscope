# Cosmoscope — Space Exploration Website

Cosmoscope is a modern, responsive space exploration website that invites users to discover the wonders of the universe. Explore the eight planets, learn about space missions, and discover fascinating astronomy facts through an interactive and visually engaging interface.

## Features

- **Interactive Solar System:** Explore all eight planets and view information about their distances from the Sun, orbital periods, and known moons.
- **Space Missions:** Discover important space exploration missions, including the International Space Station, Mars Perseverance Rover, and James Webb Space Telescope.
- **Cosmic Fact Generator:** Explore interesting facts about planets, stars, and the universe.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Modern UI:** Dark space-themed design with lime-green accents and CSS-generated planetary illustrations.
- **Interactive Navigation:** Mobile menu, smooth scrolling, hover effects, and scroll animations.
- **NASA Resources:** Direct links to official space science and mission information.

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/cosmoscope-space-exploration.git
   ```

2. Navigate to the project folder:

   ```bash
   cd cosmoscope-space-exploration
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
